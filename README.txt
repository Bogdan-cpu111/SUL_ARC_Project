# SUL_ARC v1.0 Pro

**SUL_ARC** is a custom professional archiver with a unique encryption algorithm. This project was developed as an experiment in data security and GUI design using Python.

## Features
* **Custom XOR Encryption**: Secure data processing with a unique `.sul` format.
* **Modern GUI**: Built with `customtkinter` for a sleek, dark-themed experience.
* **Standalone**: Can be compiled into a single `.exe` file.

## Project Structure
* `main.py`: Entry point of the application.
* `core/`: Encryption and compression engines.
* `gui/`: User interface and window management.

## How to use
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python main.py`
3. To create an archive, name your file using the format: `sul.[filename].sul`
